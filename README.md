---

## What I believe

- **Models are just the beginning** — production infra, latency, and 
  reliability are where real AI engineering happens.
- **Metrics without context are noise** — I care about what a number 
  means for the user, not just the leaderboard.
- **Scope beats complexity** — a focused system that ships beats a 
  perfect one that doesn't.
- **Read the failure cases** — the edge cases tell you more about a 
  system than the happy path ever will.

## What I have shipped

[**LLM Business Automation Platform**](https://github.com/UmarAftab174) 
— Built at DARC Technologies. Modular LangChain agent workflows with 
function calling, RAG over Pinecone, and natural-language task execution 
across document generation, email automation, and business operations. 
Reduced manual operations by ~60-70%. Stack: async FastAPI, Redis, 
PostgreSQL, Docker, GCP Cloud Run.

[**MediBot**](https://github.com/UmarAftab174/medibot) — A 
production-ready AI diagnostic assistant. A custom 1D-CNN processes 
377-dimensional symptom vectors across 773 diseases with 91% accuracy. 
Under 2s conversational inference latency. Stack: FastAPI, React, Gemini 
LLM, JWT auth.

**FN Crib** — A Dockerized e-commerce platform 
built and deployed on a VPS with Laravel, PostgreSQL, Redis, and Tailwind 
CSS. Integrated Mailgun for transactional email and NOWPayments for 
crypto payments. Production live.

[**Rang**](https://github.com/UmarAftab174/rang) — An on-device AI 
mobile app that classifies plastic objects by color using a custom-trained 
CNN, built for the KHILONA toy factory's automation pipeline.

[**Healthcare Smart App**](https://github.com/UmarAftab174) — 
Multimodal anomaly detection system fusing two input streams via 
TensorFlow with sub-100ms inference latency. Real-time IoT data 
streaming over WebSockets with continuous patient alerts. Stack: Flutter, 
FastAPI, WebSockets.

[**Computer Vision Pipeline**](https://github.com/UmarAftab174) — 
YOLO + ByteTrack/BOT-Track at 30 FPS on 2+ hours of surveillance video. 
82% mAP on 8,000+ annotated samples. 45% reduction in preprocessing time.
